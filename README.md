# Graphic Design Portfolio

Temuulen Ga-ийн graphic design ажилд зориулсан статик CV + portfolio сайт.

## Агуулга

- Дан poster-уудын masonry grid, цуврал бүтээлүүдийн carousel ба бүтэн багц lightbox.
- Хөтлөгчтэй, баримт/тайлбар, мэдээлэл/танилцуулга гэсэн гурван reel ангилал.
- Reel бүр бодит video frame thumbnail-тай.
- Responsive, keyboard-friendly carousel ба reduced-motion дэмжлэгтэй.
- GitHub Pages workflow багтсан.

## Local preview

Static server-ээр энэ хавтсыг ажиллуулаад `index.html`-ийг нээнэ.

## Source safety

- Poster файлуудыг энэ тусдаа project-д хуулсан.
- Сонгосон video файлуудыг эх чанараар нь assets/videos дотор хадгалсан.
- Нууц түлхүүр, private config агуулаагүй.
